# Subscriber Cancellations Data Pipeline

This project turns the Cademycode source database into a clean, analytics-ready SQLite database and CSV export.

## Structure

- `dev/cademycode.db` — source database
- `src/pipeline.py` — ingestion, cleaning, transformation, validation, and export
- `tests/test_pipeline.py` — unit tests
- `logs/` — changelog and error log generated by runs
- `production/` — generated database and CSV
- `run_pipeline.sh` — repeatable update command

## Run

```bash
python src/pipeline.py --source dev/cademycode.db --output production/cademycode_clean.db --csv production/cademycode_clean.csv
python -m unittest discover -s tests -v
bash run_pipeline.sh
```

The script validates source changes, writes an atomic output database and CSV, and records changes or failures in `logs/`.
